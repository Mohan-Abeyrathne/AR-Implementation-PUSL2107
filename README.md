## Project Description

Interactive AR Airport is a marker-based AR application developed using A-Frame and AR.js. It displays a small airport environment when the Hiro marker is detected.

## Technologies Used

- HTML
- A-Frame
- AR.js
- JavaScript
- glTF / GLB 3D model
